Common questions

Is this safe? Where do my files go?

Everything happens right inside your web browser. Your files are not uploaded anywhere. When you close the page, they are gone.

Is it really free?

Yes. No accounts, no payments, no trial periods, and no ads.

Do I need to install anything?

No. Just click a tool above and start using it.

It isn't working — what should I try?

Try refreshing the page. If you are using a very old browser, try Chrome, Edge, Firefox, or Safari from the last couple of years.
